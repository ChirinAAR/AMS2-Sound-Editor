# AMS2 Sound Editor

Tool made for the import of custom car sounds in AMS 2, parting on a AC sound mod base

## Disclamer

The main goal of this tool is not to be "a conversion tool", but rather let sound modders add custom sounds into the game without modifying their current workflow. Any conversion of any AC sound mod must be authorized and consented by it's original author.

## What does it do
- Adds custom sounds for modded cars, with it's proper .bank file and .csdbin
- Edits car sounds of vanilla cars
- Adjust the pitch, RPM and fade ranges, and the amplification of the sound bands

### Known Issues
- Not every vanilla car sound works correctly
- Game can crash if the .bank is way too heavy
- Audio stutters on a race against cars with custom sounds
- Car sounds way quieter compared to vanilla sounds (gotta learn more about the Exhaust event)
